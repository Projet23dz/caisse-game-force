# CashPro — قاعدة البيانات + السيرفر + الـ API

برنامج تسيير الخزينة لـ **Game Force** و **ETP** — تطبيق Windows (.exe) مع سيرفر PostgreSQL محلي ووصول عن بعد عبر Tailscale.

## الحالة

| المرحلة | الحالة |
|---|---|
| 1. قاعدة البيانات (PostgreSQL 16) | ✅ 62 / 62 اختباراً ناجحاً |
| 2. الـ API (Node.js 22 + TypeScript 7 + Express 5) | ✅ 18 / 18 اختبار تكامل على قاعدة حقيقية، tsc بدون أخطاء |
| 3. الواجهة الكاملة (client/) — 3 لغات، 6 أنماط، RTL | ✅ مختبرة في Chrome (حاسوب وهاتف) |
| 4. تطبيق Windows (desktop/ — Electron) | ✅ يُبنى تلقائياً في GitHub Actions: `CashPro-Setup-x.y.z.exe` |
| 5. التحديث | الواجهة تُحدَّث من السيرفر لكل الأجهزة؛ ملف ‎.exe‎ جديد فقط عند تغيير التطبيق نفسه |

## ما يقدّمه الـ API

- **الدخول:** JWT، كلمة سر إجبارية التغيير في أول دخول، قفل 15 دقيقة بعد 5 محاولات خاطئة.
- **الأنشطة والحسابات:** خزينة / بنك / CCP، الفئات، المورّدون (إضافة مورّد جديد من نموذج الشراء مباشرة).
- **العمليات:** إيراد، مصروف، شراء، إيداع، سحب؛ تعديل الحقول غير المالية فقط؛ إلغاء بسبب؛ تصحيح = إلغاء + عملية مرتبطة؛ مرفقات PDF/صور.
- **التحويلات** داخل النشاط وبين الأنشطة (تلغي نفسها في المجمّع).
- **الشيكات:** حافظة ← إيداع ← تحصيل / رفض؛ شيك صادر ← صرف / إلغاء؛ تنبيه الاستحقاق.
- **الصندوق:** فتح، إغلاق بالعدّ الفعلي، فرق إلزامي السبب، مصادقة المسؤول، إعادة فتح للـ Admin فقط.
- **الأجور:** العمّال، تسبيق، مكافأة، خصم، دفع لا يتجاوز الباقي، كشف شهري لكل عامل.
- **لوحة التحكم والتقارير:** مؤشرات اليوم مع نسبة التغيّر، منحنى 30 يوماً، توزيع المصاريف، التقرير اليومي، الملخص اليومي/الشهري، تطوّر الرصيد.
- **سجل التعديلات** قابل للبحث والتصفية.
- **لا شيء يُمحى:** كل بيانات العملية قابلة للتعديل؛ تغيير المبلغ أو التاريخ أو الحساب يُنشئ نسخة جديدة وتبقى القديمة ظاهرة مشطوبة تحتها (معدّلة/ملغاة) مع اسم المسؤول والتاريخ والسبب.
- **الفئات:** صفحة «الفئات» للإضافة والتعديل والتعطيل، و«+ فئة جديدة» مباشرة من نموذج العملية.
- **أنواع عمليات جديدة (1.2.0):** المدير يضيف أنواعاً خاصة (اسم + دخول/خروج + لون) ولكل نوع فئاته؛ الأنواع الخمسة الأساسية ثابتة.
- **نشاط الموظفين 🔔 (1.2.0):** المدير يرى كل إضافة أو تعديل أو إلغاء قام به غيره، مع القيمة قبل/بعد، و«تمّت المراجعة».
- **الوصول عن بُعد:** عبر Tailscale الرسمي (أو VPN آخر) مثبّت على السيرفر والأجهزة — لم يعد Tailscale مدمجاً في البرنامج منذ 1.2.0.
- **الشعارات:** شعار لكل نشاط وشعار البرنامج، مع سجل الشعارات السابقة والرجوع إليها؛ رفض ملفات SVG الخطيرة.
- **التصدير:** Excel و CSV و PDF بالعربية أو الفرنسية أو الإنجليزية، مع الشعار في الرأس.
- **الصلاحيات:** المدير يحدّدها لكل مستخدم ولكل نشاط على حدة (20 صلاحية، الحسابات المسموحة، سقف المبلغ)، وتُطبَّق داخل قاعدة البيانات.

## تطبيق Windows (‎.exe‎)

- **التحميل:** GitHub ← Actions ← آخر تشغيل ناجح ← `CashPro-Setup-Windows`، أو صفحة **Releases** لكل نسخة `v*`.
- **أول تشغيل:** يطلب عنوان السيرفر (مثلاً `192.168.1.10:4600` داخل المحل، أو `cashpro-server:4600` عبر Tailscale)، ويختبره ثم يحفظه.
- **تغيير السيرفر:** من الإعدادات، أو Ctrl+Shift+S.
- **من الهاتف أو أي متصفح:** نفس العنوان في المتصفح.
- **نسخة جديدة من ‎.exe‎:** `git tag v1.0.1 && git push --tags` ← GitHub يبني الملف وينشره في Releases.

## التثبيت بضغطة واحدة على جهاز السيرفر — `CashPro-Server-Setup.exe`

ملف واحد يفعل كل شيء دون إنترنت ودون خطوات يدوية:
1. **PostgreSQL 16** مُدمج: يُهيَّأ ويُسجَّل كخدمة Windows باسم `CashPro-PostgreSQL`، ويستمع على الجهاز نفسه فقط.
2. **قاعدة البيانات** `cashpro`: الجداول، القواعد، الصلاحيات، التقارير، Game Force و ETP.
3. **المستخدمون والصلاحيات:** حسابات داخلية بكلمات سر عشوائية (في `C:\CashPro\config\cashpro.env`، للمسؤولين فقط) + الحساب `admin` / `CashPro@2026` (تغيير إجباري).
4. **تشغيل البرنامج:** السيرفر يبدأ تلقائياً مع Windows (المنفذ 4600)، والبرنامج يُفتح في نهاية التثبيت متصلاً مباشرة.
5. **اختصار CashPro على سطح المكتب** وفي قائمة «ابدأ».
6. نسخ احتياطي يومي 23:30، وفتح المنفذ 4600 للشبكة المحلية و Tailscale فقط.

إعادة التثبيت أو التحديث تحتفظ بكل البيانات في `C:\CashPro`، وإلغاء التثبيت يوقف الخدمات دون حذف البيانات.
يُختبر هذا التثبيت تلقائياً في GitHub على جهاز Windows حقيقي قبل بناء الملف: تثبيت، دخول، تحديث، نسخة احتياطية.

**الأجهزة الأخرى:** `CashPro-Setup.exe` (الخفيف) ثم إدخال عنوان السيرفر.

## Windows 7 / 8

- **الأجهزة (البرنامج):** `CashPro-Setup-Win7.exe` — نفس البرنامج مبنيّ بـ Electron 22، آخر نسخة تدعم Windows 7، لنسختي 32 و 64 بت (المثبّت يختار تلقائياً).
- **المتصفح على Windows 7:** Chrome 109 (آخر نسخة لـ Windows 7) يفتح الواجهة أيضاً.
- **السيرفر:** يتطلّب Windows 10 أو أحدث (PostgreSQL 16 و Node.js 22 لا يعملان على Windows 7).
- **Tailscale** يتطلّب Windows 10 أو أحدث: جهاز Windows 7 يتصل بالسيرفر عبر الشبكة المحلية فقط (أو عبر «subnet router»).

### نسخة تجريبية كاملة على Windows 7 (للتجربة فقط)

`CashPro-Essai-Win7.zip`: مجلد محمول (PostgreSQL 15 + نافذة CashPro بمحرّك Electron 22) لـ Windows 7 SP1 64 بت.
فكّ الضغط ثم شغّل `CashPro-Essai.cmd`. البيانات داخل مجلد `data`. **ليست سيرفراً**: بدون تحديثات أمنية.

### سيرفر تجريبي على Android (Termux — للتجربة فقط)

`CashPro-Android.tar.gz` (من GitHub ← Releases ← `android-latest`). في Termux (من F-Droid):
```bash
termux-setup-storage
tar xzf ~/storage/downloads/CashPro-Android.tar.gz -C ~
bash ~/cashpro-android/start.sh        # أضف --wifi لفتحه لأجهزة نفس الشبكة
```
ثم Chrome على `http://127.0.0.1:4600`. البيانات في `~/cashpro-android/data`.

### تطبيق Android — `CashPro.apk`

من GitHub ← Releases ← `android-latest`. داخل المحل: عنوان السيرفر في الشبكة المحلية (مثلاً `192.168.1.10:4600`).
من خارج المحل: ثبّت تطبيق **Tailscale** الرسمي على الهاتف وشغّله، ثم اكتب عنوان السيرفر في Tailscale (مثلاً `cashpro-server:4600`).
العناوين تظهر في CashPro ← الإعدادات ← «الوصول عن بُعد».

## التثبيت اليدوي على السيرفر (بديل)

1. ثبّت **PostgreSQL 16** و **Node.js 22 LTS**.
2. انسخ المستودع (أو حمّله من GitHub) إلى السيرفر، ثم في PowerShell (كمسؤول):
   ```powershell
   cd C:\cash-gameforce\server-setup
   powershell -ExecutionPolicy Bypass -File .\install-database.ps1
   powershell -ExecutionPolicy Bypass -File .\install-api.ps1
   powershell -ExecutionPolicy Bypass -File .\schedule-backup.ps1 -OffsitePath "E:\CashPro-Backups"
   ```
3. تأكّد أن `http://localhost:4600/api/health` يردّ بـ `"ok": true`.
4. الدخول الأول: `admin` / `CashPro@2026`، وتغيير كلمة السر إجباري.
5. أدخل **الأرصدة الافتتاحية** لكل حساب قبل أول عملية، لأنها تُقفل بعدها.

## Tailscale (الوصول من خارج المحل)

منذ 1.2.0 لم يعد Tailscale مدمجاً في CashPro: يُثبَّت تطبيق Tailscale الرسمي (أو أي VPN آخر) بشكل مستقل.

1. ثبّت Tailscale على السيرفر وعلى كل جهاز سيستعمل البرنامج من خارج المحل، وسجّل الدخول بنفس الحساب.
2. فعّل **MagicDNS** وسمِّ السيرفر `cashpro-server` (لوحة Tailscale ← Machines ← Edit machine name)؛ بهذا تبقى عناوين الأجهزة القديمة صالحة.
3. على السيرفر: قائمة Tailscale ← **Run unattended**، وفي لوحة Tailscale ← **Disable key expiry** للسيرفر، حتى لا يُطلب تسجيل الدخول من جديد.
4. البرنامج على الأجهزة البعيدة يتصل بـ `http://cashpro-server:4600`.
5. PostgreSQL لا يُفتح للشبكة أبداً (يستمع على localhost فقط). المنفذ 4600 مفتوح للشبكة المحلية ونطاق Tailscale فقط، وليس للإنترنت.
